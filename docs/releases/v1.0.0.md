# Devdevian V1 — From conversation to contribution

Devdevian is an open-source forum for developers, available in your browser and terminal. V1 brings technical conversations, human code review and shared project work into one account and permission system.

[Watch the new film](https://www.youtube.com/watch?v=qjFs2yy5uz0) · [Try Devdevian](https://devdevian.vercel.app/) · [Read the documentation](https://devdevian.vercel.app/docs)

## From a question to shared work

- **Conversations:** ask questions, discuss tradeoffs, share projects and request code feedback. Threaded replies, accepted answers, follows and notifications help keep a useful discussion going.
- **Project Workspaces:** keep focused work requests with a project, link discussions and retain multi-file code revisions as the implementation changes.
- **Review Flow:** invite a named reviewer and record outcomes against the exact code snapshot. A verdict on an earlier revision never silently approves a newer one.
- **Rooms:** share a task board, claim or assign work, track progress, and pin decisions with retained history.
- **Contributions:** submit a task result with its context and optional GitHub PR evidence, then keep the outcome with the project.
- **My Work:** find review invitations, requested changes, replies awaiting an answer, assigned tasks and submitted results in one place.

## Your GitHub workspace

Connect the GitHub App to repositories you select. Browse issues, pull requests, diffs and checks using the connected user's permissions. Select changes for a Devdevian code review and link repository work to project tasks. Connecting the workspace is separate from GitHub sign-in.

[GitHub workspace guide](https://devdevian.vercel.app/docs/github-app) · [Project participation guide](https://devdevian.vercel.app/docs/project-participation)

## The same forum in your terminal

The CLI includes a live keyboard-driven workspace, local file and Git diff selection, code review threads, Rooms, Projects, Events, GitHub context, My Work and appearance preferences.

```sh
npm install -g @tenyokjs/devdevian-cli@alpha
devdevian login
devdevian tui
```

Requires Node.js 24+. Only explicitly selected local files are read. Publishing uses preview and confirmation; browser and terminal share server-side access rules.

**The CLI remains an alpha:** this release includes the existing `0.22.0-alpha.1` milestone and does not publish a new npm package or promote the terminal client to stable.

## Clear participation and practical documentation

Project visibility and contribution access are separate. Owners can allow open participation or approve specific contributors; approval does not grant access to a private community. Contributor credits follow visible work.

The documentation site includes a starting dashboard, 25 guides, section search with destination highlights, code and Markdown copying, interactive diagrams, product screenshots, and light/dark themes.

## Upgrading

Browser/API is now **1.0.0**. This release consolidates the shipped Workspaces, Review Flow, Rooms, Contributions, GitHub App, My Work, participation and documentation milestones, plus the new launch film.

There are **no new database migrations or GitHub permissions** compared with browser/API `0.10.1`. Existing data is preserved. Older self-hosted installations must follow the migrations for the intermediate versions in the [deployment guide](https://github.com/Tenyokj/devdevian/blob/main/docs/deployment.md); changing the version label does not skip those steps.

Devdevian remains in active development. V1 marks this product milestone, not a guarantee of error-free operation or unlimited hosting capacity. Keep operational backups and report reproducible problems.
